# Project Statement: Command-Line Snake Game

## Problem Statement

This project is a command-line Snake game made with Python. The player controls a snake using the W, A, S, and D keys. The goal is to collect objects, earn points, and avoid hitting the walls or the snake's own body. Some objects give special effects, while a bomb ends the game.

The project applies programming concepts such as variables, conditions, loops, lists, functions, random choices, and keyboard input.

## Scope

The project shows a text-based menu,instructions for game , snake movement, object generation,who score high , special object effects, collision handling, and restart or quit options. It runs easily in a terminal and does not require a graphical interface or extra Python packages.

## Target Users

The users are students and beginners who want to play a simple terminal game and see basic Python programming concepts used in a complete program.

## High-Level Features

- Main menu and instructions
- Snake movement using W, A, S, and D
- Score updates when objects are collected
- Special objects with different effects
- Wall and self-collision handling
- Restart or return to the menu
